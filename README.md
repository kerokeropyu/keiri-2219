# keiri-2219

経理の2219処理を自動で行うCUIツールです。「科目２０００～５０００未満」シートの内容をもとに、
「0384仮払い消費税」シートへ税率・科目・税額を入力します。

## 準備

```powershell
uv sync
```

入力ファイルはExcelで`.xlsx`形式に保存してください。`.xls`は読み込めません。

## 実行

```powershell
uv run keiri-2219 "LOOKGOOD.xlsx"
```

元のファイルは変更せず、`LOOKGOOD_2219処理済み.xlsx`を作成します。

| オプション | 内容 |
|---|---|
| `-o`, `--output` | 出力ファイルを指定する |
| `--log-dir` | ログの保存先を指定する（初期値: `logs`） |

同じ名前の出力ファイルがある場合は上書きせず、`LOOKGOOD_2219処理済み(2).xlsx`のように連番を付けて保存します。
ただし`-o`で指定したファイルがすでにある場合は、エラーで終了します。

## 入力ルール

対象は「0384仮払い消費税」シートのE列が2219の行です。

| 行の状態 | 処理 |
|---|---|
| H・K・P列が空 | 税行の下の明細をもとに、税率・科目・税額を入力する |
| H・K・P列のどれかに値があり、税額列が空 | 空の税額列にJ/O列の金額を入力する |
| 税額列（L〜N、Q〜S）に値がある | 入力済みとして何もしない |

- **セット:** A列が2219で、親伝票№（L列）が税行の伝票№と同じ、税行より下の行を明細として扱います。
- **金額確認:** `明細合計×税率`と税額の差が明細の行数（円）以内なら正しいとみなします。
- **複数科目:** 税額は`科目小計×税率`（切り捨て）で、端数は金額が最大の科目で調整します。
- **追加行:** 元の行の直下に追加し、A〜G列を複写します。J/O列は空欄です。
- **目印:** 入力した行（元の行・追加行・税額のみ入力した行）は、A列の背景を赤く塗ります。
- **税率:** 課税区分（U列）で決めます。「外」は明細合計と税額の比率から10%か8%を判定します。
  課10は10%、課08（課8）は8%です。
- **税率の確認:** 税額だけを入力する行で、U列が課10・課08・課8のときは、H列の税率と一致する場合だけ入力します。

金額確認NGの行や、税行の下に明細がない行は入力しません。理由はログに残ります。

## 保存前の一致チェック

保存する前に、E列が2219で税額列（L〜N、Q〜S）に値がある行を伝票№ごとに合計し、
借方は`L〜N列の合計＝J列`、貸方は`Q〜S列の合計＝O列`になっているかを確認します。
追加した行は元の行と同じ伝票№として合算します。

一致しない伝票が1件でもあれば、内容を画面とログに出し、ファイルは保存せずに終了します（終了コード1）。

## ログ

`logs/keiri_2219.log`に保存します（exeの場合は、exeと同じフォルダの`logs`）。1MBで切り替え、過去の5世代を残します。

## exe化

### 作り方

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

`dist\keiri-2219.exe`ができます。Pythonが入っていないPCでも動きます。

### 使い方（経理担当者向け）

1. `keiri-2219.exe`を好きなフォルダに置きます。
2. 処理する`.xlsx`ファイルを`keiri-2219.exe`にドラッグ＆ドロップします。
3. 黒い画面に結果が表示されます。確認したらEnterキーを押して閉じます。

- 処理済みのファイルは、元のファイルと同じフォルダに作られます。
- ログは、exeと同じフォルダの`logs`に保存されます。
- exeをダブルクリックしただけの場合は、使い方を表示します。
